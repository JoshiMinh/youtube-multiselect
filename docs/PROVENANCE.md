# Provenance

YouTube Multiselect is a **clean-room, from-scratch implementation**. It was inspired by
the feature set of the third-party extension "Multiselect for YouTube", but **no code,
markup, styles, icons, strings or other assets were copied** from it.

## What was inspected (2026-10-26)

| Item | Finding |
| --- | --- |
| Listing | [addons.mozilla.org/firefox/addon/multiselect-for-youtube](https://addons.mozilla.org/en-US/firefox/addon/multiselect-for-youtube/), developer "Pollux", homepage ms4yt.com, version 4.0 |
| Declared license | AMO listing states **Mozilla Public License 2.0**. AlternativeTo describes it as proprietary. No public source repository is linked from AMO. |
| Package | `latest.xpi` from AMO (129,781 bytes), unpacked into a scratch folder and **not executed**. |
| License notices in package | **None found.** No `LICENSE`/`NOTICE` file; no copyright or license headers. `js/*.js` are obfuscated bundles. |
| Manifest | MV3; `storage` + `clipboardRead` permissions; content scripts on `https://www.youtube.com/*` including a `MAIN`-world script; a `Ctrl+M` command; options page. |

Only the manifest and file headers were read, to answer the licensing question. The
obfuscated logic was not studied or reused.

## Consequences

- MPL-2.0 is a file-level copyleft that applies to copies or modifications of MPL-covered
  files. This project contains none, so no MPL notices are required or retained.
- Ideas taken at the feature level only: "checkbox per playlist row", "Shift-click ranges",
  "export selection". The interface, architecture, identity strategy and reliability
  design here are independent.
- If code from the original is ever considered for reuse, first obtain its actual source
  under a confirmed license, then keep that file's MPL-2.0 header and record it here.

## Third-party dependencies

All runtime/build dependencies come from npm under their own licenses (WXT: MIT, React: MIT,
etc.). The production bundle includes React and react-dom (MIT). Icons in `public/icon/` are
generated by `scripts/generate-icons.mjs` in this repository.
